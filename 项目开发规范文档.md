### 1. 数据模型（Models）

#### 1.1 基本规范

**✅ 标准示例：**
```python
"""
模块名称：风险预警模块
@author: 开发者姓名
@contact: QQ/邮箱
@Created on: 2025-11-27
@Remark: 功能说明
"""
from django.db import models
from dvadmin.utils.models import CoreModel

class RiskTag(models.Model):
    """
    风险标注表

    映射到 intelligence 数据库的 risk_tags 表
    """
    complaint = models.ForeignKey(
        'Complaint',
        on_delete=models.DO_NOTHING,  # 只读模式
        db_column='complaint_id',
        to_field='id',
        related_name='risk_tags',
        verbose_name='工单'
    )
    is_risk = models.BooleanField(
        default=False,
        verbose_name='是否风险'
    )
    risk_category = models.CharField(
        max_length=50,
        null=True,
        blank=True,
        verbose_name='风险类别'
    )
    created_at = models.DateTimeField(
        auto_now_add=True,
        verbose_name='创建时间'
    )

    class Meta:
        db_table = 'risk_tags'
        managed = False  # 映射现有表，不由 Django 管理
        verbose_name = '风险标注'
        verbose_name_plural = verbose_name
        ordering = ['-created_at']

    def __str__(self):
        return f"{self.complaint_id} - {self.risk_category}"
```

#### 1.2 关键要点

1. **模块注释** - 必须包含作者、时间、功能说明
2. **字段 verbose_name** - 所有字段必须有中文名称
3. **Meta 配置** - 必须包含 db_table, verbose_name, ordering
4. **只读映射** - 使用 `managed = False` 映射现有表
5. **外键配置** - 使用 `on_delete=models.DO_NOTHING` 用于只读关系
6. **__str__ 方法** - 提供清晰的字符串表示

"""
风险预警序列化器

from rest_framework import serializers
from dvadmin.utils.serializers import CustomModelSerializer
from .models import RiskTag

class RiskTagSerializer(CustomModelSerializer):

    """
    风险标注导出序列化器 (用于Excel导出)

### 3. 视图集（ViewSets）

#### 3.1 基本规范

**✅ 标准示例：**
```python
"""
风险预警视图
"""
from rest_framework import viewsets
from rest_framework.decorators import action
from rest_framework.response import Response
from django_filters import rest_framework as filters
from openpyxl import Workbook
from django.http import HttpResponse
from datetime import datetime

from .models import RiskTag
from .serializers import RiskTagSerializer, RiskTagExportSerializer
from dvadmin.utils.viewset import CustomModelViewSet

class RiskTagFilter(filters.FilterSet):
    """
    风险标注过滤器 (按工单的受理时间筛选)
    """
    # 按工单受理时间筛选
    accept_time_start = filters.DateTimeFilter(
        field_name='complaint__accept_time',
        lookup_expr='gte',
        label='受理时间开始'
    )
    accept_time_end = filters.DateTimeFilter(
        field_name='complaint__accept_time',
        lookup_expr='lte',
        label='受理时间结束'
    )

    # 按风险类别筛选
    risk_category = filters.CharFilter(
        field_name='risk_category',
        lookup_expr='exact',
        label='风险类别'
    )

    class Meta:
        model = RiskTag
        fields = [
            'accept_time_start', 'accept_time_end',
            'risk_category', 'is_risk'
        ]

class RiskTagViewSet(CustomModelViewSet):
    """
    风险预警视图集 (只读)

    list:查询风险标注列表 | retrieve:查询单个风险标注详情 | export:导出Excel
    """
    queryset = RiskTag.objects.select_related('complaint').all()
    serializer_class = RiskTagSerializer
    filterset_class = RiskTagFilter
    search_fields = ['complaint__id', 'risk_category', 'risk_reason']
    ordering_fields = ['created_at', 'complaint__accept_time']
    ordering = ['-created_at']

    # 禁用创建、更新、删除操作
    http_method_names = ['get', 'head', 'options']

    def get_queryset(self):
        """
        优化查询: 预加载关联的工单信息
        """
        queryset = super().get_queryset()
        return queryset.select_related('complaint')

    @action(methods=['get'], detail=False, url_path='export')
    def export_data(self, request, *args, **kwargs):
        """
        导出风险预警数据 (包含完整工单信息)
        """
        # 获取筛选后的查询集
        queryset = self.filter_queryset(self.get_queryset())

        # 使用导出序列化器
        serializer = RiskTagExportSerializer(queryset, many=True)
        data = serializer.data

        # 创建 Excel 工作簿
        wb = Workbook()
        ws = wb.active
        ws.title = '风险预警数据'

        # 写入表头
        if data:
            headers = list(data[0].keys())
            ws.append(headers)

            # 写入数据
            for item in data:
                row = [item.get(header, '') for header in headers]
                ws.append(row)

        # 生成响应
        response = HttpResponse(
            content_type='application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
        )
        filename = f'风险预警数据_{datetime.now().strftime("%Y%m%d_%H%M%S")}.xlsx'
        response['Content-Disposition'] = f'attachment; filename="{filename}"'

        wb.save(response)
        return response

    def create(self, request, *args, **kwargs):
        """禁用创建操作"""
        return Response({
            'code': 4000,
            'msg': '风险预警数据为只读，不支持创建操作'
        }, status=403)
```

#### 3.2 关键要点

1. **⚠️ 必须继承 `CustomModelViewSet`** - 项目标准基类
2. **过滤器配置** - 使用 `FilterSet` 实现复杂筛选
3. **跨表查询** - 使用 `field_name='relation__field'`
4. **查询优化** - 使用 `select_related` 预加载关联数据
5. **自定义 action** - 使用 `@action` 装饰器添加自定义接口
6. **只读设计** - 使用 `http_method_names` 限制方法
7. **操作说明** - 在 docstring 中说明支持的操作

### 5. 多数据库配置

#### 5.1 数据库路由器

**✅ 标准示例：**
```python
"""
数据库路由器
"""
class IntelligenceDBRouter:
    """
    智能分析数据库路由器

    将 risk_warning 应用的所有操作路由到 intelligence 数据库
    """
    intelligence_apps = {'risk_warning'}

    def db_for_read(self, model, **hints):
        """读操作路由"""
        if model._meta.app_label in self.intelligence_apps:
            return 'intelligence'
        return None

    def db_for_write(self, model, **hints):
        """写操作路由"""
        if model._meta.app_label in self.intelligence_apps:
            return 'intelligence'
        return None

    def allow_relation(self, obj1, obj2, **hints):
        """允许关系"""
        if (obj1._meta.app_label in self.intelligence_apps or
            obj2._meta.app_label in self.intelligence_apps):
            return True
        return None

    def allow_migrate(self, db, app_label, model_name=None, **hints):
        """禁止迁移"""
        if app_label in self.intelligence_apps:
            return db == 'intelligence'
        return None
```

### 2. API 接口层（api.ts）

#### 2.1 基本规范

**✅ 标准示例：**
```typescript
/**
 * 风险预警 API
 */
import { request } from '/@/utils/service'
import type { PageQuery, PageRes, InfoReq } from '@fast-crud/fast-crud'

// API 基础路径
export const apiPrefix = '/api/risk_warning/risk-tags'

/**
 * 数据接口定义
 */
export interface RiskTag {
  id: number
  complaint_id: string
  is_risk: boolean
  risk_category: string | null
  risk_reason: string | null
  created_at: string
  // 关联的工单字段
  complaint_title: string | null
  complaint_region: string | null
}

/**
 * 查询参数接口
 */
export interface RiskTagQuery extends PageQuery {
  accept_time_start?: string
  accept_time_end?: string
  accept_time_range?: string[]  // 前端用
  risk_category?: string
  is_risk?: boolean
  complaint_id?: string
}

/**
 * 获取列表
 */
export function GetList(query: RiskTagQuery): Promise<PageRes<RiskTag>> {
  return request({
    url: apiPrefix + '/',
    method: 'get',
    params: query
  })
}

/**
 * 获取详情
 */
export function GetObj(id: InfoReq): Promise<RiskTag> {
  return request({
    url: apiPrefix + `/${id}/`,
    method: 'get'
  })
}

/**
 * 导出数据
 */
export async function Export(query: RiskTagQuery): Promise<Blob> {
  const response: any = await request({
    url: apiPrefix + '/export/',
    method: 'get',
    params: query,
    responseType: 'blob'
  })
  return response.data || response
}

/**
 * 导出文件下载助手
 */
export function downloadExportFile(blob: Blob, filename?: string) {
  const url = window.URL.createObjectURL(blob)
  const link = document.createElement('a')
  link.href = url
  link.download = filename || `风险预警数据_${new Date().getTime()}.xlsx`
  document.body.appendChild(link)
  link.click()
  document.body.removeChild(link)
  window.URL.revokeObjectURL(url)
}
```

#### 2.2 关键要点

1. **⚠️ 必须使用独立函数导出** - 不要用对象导出
2. **函数命名规范** - `GetList`, `GetObj`, `AddObj`, `UpdateObj`, `DelObj`, `Export`
3. **apiPrefix 导出** - 使用 `export const` 导出
4. **类型定义** - 使用 TypeScript 接口定义
5. **Blob 处理** - `responseType: 'blob'` 时返回 `response.data`

  dict

    // ✅ 在这里统一处理默认过滤和参数转换

      ...query,
      is_risk: true  // 默认过滤条件

      requestQuery.accept_time_start = query.accept_time_range[0]
      requestQuery.accept_time_end = query.accept_time_range[1]
      delete requestQuery.accept_time_range

    return await api.GetList(requestQuery)

## 数据库规范

### 1. 表设计规范

#### 1.1 基本要求

- **主键命名**: 使用 `id`，自增整数或字符串
- **时间字段**: `created_at`, `updated_at` (DATETIME)
- **外键字段**: 使用 `{关联表名}_id` 命名
- **布尔字段**: 使用 `is_xxx` 命名（如 `is_risk`）
- **索引**: 为外键和常用查询字段添加索引

#### 1.2 字段类型选择

| 用途 | 推荐类型 | 示例 |
|------|---------|------|
| 主键 | INT AUTO_INCREMENT 或 VARCHAR(50) | id |
| 布尔值 | TINYINT(1) | is_risk |
| 短文本 | VARCHAR(255) | title, category |
| 长文本 | TEXT | content, reason |
| 日期时间 | DATETIME | created_at, accept_time |
| 枚举 | VARCHAR(50) + 字典表 | status, type |

## 常见错误和解决方案

### 错误1：crudExpose不能为空

**错误信息：**
```
Uncaught Error: crudExpose不能为空，请给useCrud传入{crudExpose}参数
```

**原因：**
没有正确使用 `useExpose` 创建 `crudExpose`

**解决方案：**
```typescript
// ❌ 错误写法
const { crudBinding, crudRef, crudExpose } = useCrud({ createCrudOptions })

// ✅ 正确写法
const crudRef = ref()
const crudBinding = ref()
const { crudExpose } = useExpose({ crudRef, crudBinding })
const { crudOptions } = createCrudOptions({ crudExpose })
useCrud({ crudExpose, crudOptions })
```

---

### 错误2：r.loadDict is not a function

**错误信息：**
```
TypeError: r.loadDict is not a function
```

**原因：**
使用了 `dict-select` 但没有正确配置字典

**解决方案：**
```typescript
// ❌ 错误写法
type: 'dict-select',
dict: { data: [...] }

// ✅ 正确写法
import { dict } from '@fast-crud/fast-crud'
import { dictionary } from '/@/utils/dictionary'

type: 'dict-select',
dict: dict({
  data: dictionary('risk_category')
})
```

### 错误7：Blob 文件下载失败

**错误信息：**
```
TypeError: Failed to execute 'createObjectURL' on 'URL'
```

**原因：**
响应拦截器返回完整 response 对象，需要提取 Blob

**解决方案：**
```typescript
// ✅ 从 response.data 提取 Blob
export async function Export(query: RiskTagQuery): Promise<Blob> {
  const response: any = await request({
    url: apiPrefix + '/export/',
    method: 'get',
    params: query,
    responseType: 'blob'
  })
  return response.data || response  // ← 关键
}
```
